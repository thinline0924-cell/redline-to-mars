# REDLINE TO MARS(レッドライン・トゥ・マーズ)

1990年代のアメリカで、ロケットを開発して火星へ行き、**飛行士を生きて地球へ帰す**ことを目指す戦略ボードゲームです。
ローポリ(角ばった少ない面で作る3D)の事務机を、一人称視点(自分の目から見た視点)で見下ろして遊びます。ブラウザだけで動きます。

- 机の上のボードに、地球・火星・軌道のマスと宇宙船のコマが並びます
- 机の物はクリックできます:コンピューター=開発、電話=飛行士、地球=組み立て、ボード=宇宙船、FAX=書類、カレンダー=記録、緑の大きなボタン=次の月へ
- 遊び方は、ゲームの中の「? 遊び方」でいつでも読めます
- 進み具合はブラウザに自動で保存されます(「続きから」で再開)

## 公開のしかた(Render・無料)

サーバーのプログラムも APIキーも要りません。

1. <https://dashboard.render.com> にログインし、右上の「New +」→「**Blueprint**」を選びます
2. このリポジトリ(`redline-to-mars`)を選びます
3. `render.yaml`(設計図)が読み込まれるので、「Apply」を押します
4. 1〜2分で `https://redline-to-mars.onrender.com`(名前が使われていれば別の名前)が開けるようになります

> うまく表示されないときは、ブラウザを最新にするか、Chrome / Edge / Safari で開いてください(3D表示に WebGL という機能を使います)。

## ファイルの役割

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨組み |
| `style.css` | 見た目(ベージュの枠+黒板のパネル、右下の状態バー) |
| `js/data.js` | ルールの数字(技術・部品・難しさ・出来事)。バランスを変えるときはここ |
| `js/game.js` | ルールの計算(画面とは切り離してある) |
| `js/scene.js` | 3Dの部屋・机・ボード(Three.js) |
| `js/main.js` | パネル・ダイアログ・保存 |
| `js/audio.js` | 効果音 |
| `render.yaml` | Render の設計図(静的サイト) |
| `tests/check-rules.mjs` | ルールの点検(Node.js がある環境で `node tests/check-rules.mjs`) |
